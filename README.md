# 留學帳本

留學帳本是一個用瀏覽器開啟的多幣別記帳工具。它把每次換匯的本金與手續費連到後續的外幣消費，讓你能用一種基準貨幣看總支出，也能按原幣查看實際支付金額。

## 開始使用

1. 在 GitHub 開啟 [`index.html`](index.html)，點檔案頁面的下載圖示，把檔案存到電腦。
2. 用新版 Chrome 開啟下載的檔案。記帳、成本計算、統計及旗幟顯示可離線使用。
3. 第一次使用可在「帳本設定」選擇基準貨幣，接著新增一筆換匯，建立外幣帳戶後即可記錄消費。

若要沿用先前的帳本，可在同一瀏覽器以新版檔案替換原位置的同名檔案，也可以先匯出舊帳本的 JSON 備份，再從新版的「帳本設定」匯入。

## 主要功能

- **換匯與消費**　換匯本金和手續費可分別選幣別。使用其他幣別付款時，可輸入該筆交易的匯率，預覽折合基準貨幣的成本。
- **外幣帳戶**　查看餘額、手續費前後的平均成本匯率，以及剩餘外幣的對應成本。換匯與消費明細也可展開比較手續費前後的成本。
- **支出統計**　依月份查看每日支出和類別分布。可切換全部消費的基準幣總額，也可查看以指定外幣實際支付的金額。
- **交易地點**　換匯與消費都可以手動填寫地點，也可使用裝置定位查詢附近的店名或地址。
- **最近刪除**　移除的交易可在「最近刪除」復原。復原後會按原交易順序重算成本及餘額。

## 成本怎麼算

每個外幣帳戶分別維護手續費前與手續費後的移動加權平均成本。新增換匯時，系統會把原有餘額的剩餘成本與本次取得成本相加，再除以換匯後的外幣餘額。消費會依當時的平均成本分攤。帳本的全部支出以含費成本加總。

例如用 CNY 1,600 換到 EUR 200，另付 CNY 30 手續費。每歐元未含費成本為 CNY 8.00，含費成本為 CNY 8.15。之後花 EUR 50，這筆消費的未含費成本是 CNY 400.00，含費成本是 CNY 407.50。

## 資料、備份與定位

交易和最近刪除記錄存於目前瀏覽器。可在「帳本設定」匯出與匯入 JSON 備份，搬移帳本時請一起保存備份檔。

點「使用目前位置」時，瀏覽器會要求定位權限。查詢地點名稱需要連線，並將座標送給 Photon 地圖服務。查詢結果可能是附近的地點，存檔前可以修改名稱。若查詢失敗，可直接手動輸入。

## 原始碼與重建

| 路徑 | 用途 |
| --- | --- |
| `index.html` | 可直接開啟的單一 HTML 檔 |
| `src/` | 介面、樣式與帳務計算 |
| `assets/flags/` | 內嵌到應用程式的旗幟圖片 |
| `scripts/build.mjs` | 將原始碼與旗幟合併成 `index.html` |

修改原始碼後，在儲存庫根目錄使用 Node.js 重新產生 `index.html`。

```sh
node scripts/build.mjs
```

旗幟圖片來自 [Flagpedia](https://flagpedia.net/download)。地點查詢使用 [Photon](https://github.com/komoot/photon) 和 [OpenStreetMap](https://www.openstreetmap.org/copyright) 資料。
